# habitmaker

Still a work in progress, 
Have used:
- BLoC for state management
- HiveCE for local storage
- Shared Preferences for theme and logic
- Made use of Google fonts
- Have used lottie files to make the app feel lively

Has 3 main screens:
- Dashboard: It shows all the active habits in cards. Showing the streak, target days, completion percentage in a circular progress bar.
- Habit Detail: It shows about the current streak, target goal, remaining days and current status.
- Archived: It shows all the archived habits. User can choose to delete a habit or bring it back to active screen.
- Add Habit: It allows user to create a habit, making user enter the habit name, description and target days for that habit. 

Yet to implement:
- Firebase login
- notifications
